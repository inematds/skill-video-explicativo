🎬 Base prompt — from basic to advanced

The starting point for any HyperFrames video. It specifies the subject, instructional progression, both formats, and the final INEMA.CLUB CTA—all in a single request.

prompt-base.txt 📋 copy prompt
Make an explainer video about {ASSUNTO}, from beginner to advanced, in 16:9 and 9:16, ending with the INEMA.CLUB CTA. Use the video-explicativo skill. Generate a complete script in PT-BR with 6 to 8 scenes, narration via pf_dora --speed 0.98, a premium dark palette (#0D1321 base), and Inter typography. The final scene must be the standard INEMA.CLUB CTA with the logo and URL inema.club. Render both formats.
What it does

Triggers the complete skill: a structured scene-by-scene script, local TTS narration with pf_dora --speed 0.98, premium dark CSS animations and dual export (1920×1080 + 1080×1920). The final scene follows the standard INEMA.CLUB CTA template, with a 0.45s fade-in.

💡
When to use

Use as a starting point for any new topic. Replace {ASSUNTO} by topic—for example: "Interactive Git rebase", "how DNS works", "introduction to n8n".

Variations
One format only

Replace "in 16:9 and 9:16" with just "in 16:9" to save render time when you don't need the vertical format.

More scenes

Add "with 10 scenes and code examples" for more in-depth content — good for technical tutorials.

Specific tone

Add "direct tone with no jargon" or "technical tone for senior developers" to calibrate the narration.

📱 Vertical Shorts prompt — strong hook, 60-90s

For Reels and YouTube Shorts: exclusively 9:16 format, compact duration (~60-90 seconds), and an opening scene that hooks viewers in under 3 seconds—the “hook.”

prompt-shorts.txt 📋 copy prompt
Create a video in Shorts/Reels format about {ASSUNTO}. 9:16 only (1080×1920). Total duration: ~75 seconds. Scene 1 must have a strong hook—a question or impactful statement that appears on screen in less than 3 seconds, with no narration during the first 2s. Use pf_dora narration --speed 1.02 (a little faster). No more than 5 scenes. End with the INEMA.CLUB CTA.
What it does

Generates only the vertical format (--vertical enabled), with the build-index.mjs rewriting the canvas to 1080×1920. The narration uses pf_dora --speed 1.02 — slightly faster than the default — and the script is optimized for retention in the first 3 seconds.

✓ Shorts best practices
  • ✓ Visual Hook in the First 2–3 Seconds
  • ✓ Maximum 5 scenes — each with a clear purpose
  • ✓ Slightly faster narration (speed 1.02)
  • ✓ Large text — readable on a phone without headphones
✗ Common Shorts mistakes
  • ✗ Start with an intro with a logo that’s too slow
  • ✗ More than 90 seconds — the algorithm penalizes it
  • ✗ Small text or text in an area covered by the app UI
  • ✗ Crop 16:9 video — always generate in native 9:16
💡
When to use

Ideal for quick disclosure on Instagram Reels, TikTok, and YouTube Shorts. It works very well for standalone tips ("1 thing you didn't know about X") or one-step mini-tutorials.

🎨 Prompt to change the mood/palette

Change the video's visual identity without rewriting the script. Useful for creating versions in a client brand's colors, a light theme (light mode), or a completely different palette.

prompt-paleta.txt 📋 copy prompt
Recreate the video about {ASSUNTO} using a {PALETA} palette instead of the default dark amber. Keep the same script and narration already generated. Change only: base background color, accent color, secondary text color, and gradients. {PALETA} can be: "dark purple with cyan" (bg #110a1f, accent #a855f7, cyan #38bdf8), "neon dark green" (bg #0a1a0f, accent #22c55e, cyan #34d399), or a custom hex specification. Render in 16:9 and 9:16.
What it does

The skill replaces the color variables in the composition-template.mjs and in the scene CSS. The script (narration-template.sh) is reused, saving TTS time. Only the visual render is refreshed.

🏁 Prompt to change the final CTA

Replace the default INEMA.CLUB end scene with your client's brand or URL — or your own brand — while keeping the rest of the video intact.

prompt-cta.txt 📋 copy prompt
In the video about {ASSUNTO} that you generated, replace the final INEMA.CLUB scene with the {MARCA_CLIENTE} brand CTA. The new final scene should display: the logo or name "{NOME_DA_MARCA}", URL "{URL_DA_MARCA}", and the call-to-action text "{TEXTO_CTA}" (e.g., "Visit now and get started for free"). Keep the 0.45s fade-in and the same premium dark style as the other scenes. Render both formats with the new scene.
What it does

The skill replaces only the last scene in the HTML project. The FADE=0.45 e o TAIL=0.9 are preserved for timing consistency. The other scenes and all previous narration are reused — only the final scene is re-recorded and re-rendered.

⚠️
Pay attention to commercial use

When changing the CTA for a client, make sure you have the rights to the logo and visual identity used. HyperFrames does not validate intellectual property—you are responsible for that.

✓ Good final CTAs
  • ✓ Short, readable URL (no visible UTM parameters)
  • ✓ Clear call-to-action text: "Visit", "Try it", "Learn more"
  • ✓ White/transparent logo version (dark background)
  • ✓ Keep the 0.45s fade-in so it doesn’t feel abrupt
✗ CTA that doesn't work
  • ✗ URL too long — impossible to read in 3 seconds
  • ✗ Colored logo on a dark background with no contrast
  • ✗ Passive text: "Check it out if you want" — no urgency
  • ✗ Generic CTA unrelated to the video topic

⏱️ Prompt to adjust duration and pacing

Precise control over the video’s total runtime — shorten it to ~60s for social distribution or extend it to 3-5min for denser educational content.

prompt-duracao.txt 📋 copy prompt
In the video about {ASSUNTO}, adjust the duration to ~60 seconds: reduce the number of scenes to 4, shorten each scene’s narration to no more than 12 seconds of audio, and use pf_dora --speed 1.05 (faster narration). Keep LEAD=0.5 and TAIL=0.9 in the scenes, but reduce the FADE to 0.3s between scenes. Regenerate the narration and render both formats.
What it does

Adjust three pacing variables in sequence: number of scenes, TTS speed (--speed 1.05) and transition duration (FADE=0.3). O LEAD=0.5 e TAIL=0.9 are kept to avoid abrupt cuts in the narration — only the middle section is compressed.

HyperFrames timing parameters
Scene variables
  • LEAD=0.5 — silence before narration (seconds)
  • TAIL=0.9 — silence after narration (seconds)
  • FADE=0.45 — cross-fade duration between scenes
TTS speed
  • --speed 0.95 — slow, instructional
  • --speed 0.98 — INEMA.CLUB standard
  • --speed 1.02 — slightly more energetic
  • --speed 1.05 — compact, Shorts
💡
When to use

Use when you already have a generated video but the client asked for a shorter version, or when you want to reuse the content in a different format (e.g., a 3-minute course video → a 60-second teaser for Stories).

🔧 Prompt to regenerate just one scene

Precision surgery: change only one specific scene without reprocessing the entire video — ideal for correcting narration errors, adjusting animation, or changing slide text.

prompt-regenerar-cena.txt 📋 copy prompt
In the video about {ASSUNTO}, redo only scene {N} with this change: {DESCRICAO_DA_MUDANCA}. Keep all other scenes and their narration intact. Regenerate only the audio for scene {N} with pf_dora and render the final video with the scene replaced. Examples of changes: "correct 'HTTP' to 'HTTPS'", "add an arrow diagram showing the flow", "change the scene title to 'Step 2: Configuration'".
What it does

The skill identifies the HTML block for scene N, applies the change, regenerates only the .mp3 of that scene via pf_dora --speed 0.98, and re-concatenates the final MP4 via FFmpeg—without touching the other audio tracks or rendered frames.

✓ Good changes for a scene
  • ✓ Fix a spelling or technical error in the text
  • ✓ Add or remove a visual element (arrow, diagram)
  • ✓ Shorten the narration of a scene that ran too long
  • ✓ Replace one animation with a clearer one
✗ When to use the full prompt
  • ✗ A change in tone or structure affects every scene
  • ✗ Reorder scenes — affects concatenated audio
  • ✗ Change the palette (use the palette prompt, topic 3)
  • ✗ Add a new scene in the middle — renumber the others
💡
Efficiency tip

If you get more than 3 scenes wrong, it's faster to regenerate the entire video with the corrected base prompt than to apply 3 individual patches. Use the scene patch for 1–2 surgical fixes.

✍️ How to write good prompts for the skill

A well-written prompt reduces back-and-forth — and produces better videos on the first try.

1️⃣
Specify the audience

Say "for beginner developers" or "for non-technical managers." The script changes radically depending on who will watch it.

2️⃣
Give the video objective

"The viewer should know how to configure X by the end" is much better than "explain X." A clear goal makes for a focused script.

3️⃣
Specify the target format

Explicitly say "16:9 and 9:16" or "9:16 only." The skill doesn't assume the format—if you don't specify, it will ask.

4️⃣
Mention concrete examples

If you have a reference video (“in the style of video X”), describe what you like about it. That guides the tone of the animations and narration.

💎
Prompt golden rule

If you can describe the video in one clear sentence — “a 60s tutorial on Git rebase for devs who already know basic Git, without jargon, ending with the INEMA.CLUB CTA” — the skill can execute without extra questions. The more specific you are, the fewer iterations it takes.
